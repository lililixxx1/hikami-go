```

```

## 二、分区

**科技 → 软件应用**

理由：B 站「科技」一级分区下「软件应用」最契合（开源软件演示）。不要选「科技·计算机知识」，那是教学向；也不要选「生活·日常」，受众不匹配。

## 八、发布时机

- **最佳时段**：工作日 19:00-21:00（B 站晚高峰），或周末 14:00-16:00
- **避开**：周一上午（流量低谷）、节假日第一天（被官号挤压）
- **首发建议**：周三或周四晚上 20:00 发布，给周末发酵时间

## 九、发布后 24 小时动作

1. **0-1h**：盯评论区，每个评论都回（B 站算法看互动率）
2. **1-6h**：发动态带视频链接，「刚发了新视频，做个直播回顾工具」
3. **6-24h**：如果数据起得来（播放 >1000），考虑投 50-100 B 币「起飞」推一波
4. **24h+**：把视频链接发到相关群（开源群 / VTuber 群 / Go 开发者群），不要硬广，配「做了个小工具求反馈」
