# AI 工具操作指南

> 4 个环节的逐步操作：配音 / 片头 B-roll / 字幕 / 封面。每节都有「输入 → 工具 → 输出 → 修剪」四步。

---

## 一、剪映 AI 配音（核心，所有旁白都走这）

### 工具
剪映 PC 版（免费）：https://www.capcut.cn/

### 操作
1. 新建项目，导入一张占位图片（或你的录屏素材）拖到时间轴。
2. 顶部「文本」→ 新建文本框 → 粘贴 `01-narration-script.md` 正文（不含 `---` 分隔线和段标题，只要正文）。
3. 选中文本框 → 右侧「朗读」按钮（或在文本面板找「文本朗读」）。
4. **音色选择**（推荐顺序）：
   - 男声：「解说小哥」「知性青年」「沉稳男声」
   - 女声：「温柔学姐」「电台女主播」「甜妹」
   - ❌ 避开：「动漫小哥哥/小姐姐」（太活泼）、明显带口音的
5. **语速**：调到 0.9x（默认 1.0x 偏快）。
6. 点「生成音频」，等 30 秒，音频出现在时间轴。
7. 把生成的音频单独导出（右键 → 导出，mp3 或 wav），存到 `配音.mp3`。

### 断句修剪
剪映 AI 配音在 `。` `！` `？` 处自动停顿。如果发现某句停顿不够，回到文本在那句末尾多加一个 `。`，重新生成。

### 进阶：分句生成（推荐）
一次性生成 620 字可能出错或停顿不自然。**分 10 段生成**（对应 S1-S10），每段单独生成，最后在时间轴拼起来，可控性高得多。段与段之间手动加 0.5-1s 静音过渡。

## 二、可灵 / 即梦 片头 B-roll（5-13 秒开场画面）

### 工具
- 可灵 AI（快手）：https://klingai.com/ （图生视频，免费额度每天 6 次，够用）
- 即梦 AI（字节）：https://jimeng.jianying.com/ （备选）

### 操作（图生视频流程）
1. **先准备一张静态图**：用即梦「图片生成」或 Midjourney 生成一张「赛博朋克风格的直播间，屏幕里满是直播画面，一个人在屏幕前疲惫地看」的图。
   - Prompt（即梦/通用）：`赛博朋克风格直播间，多块悬浮屏幕显示各种直播画面，一个年轻人坐在屏幕前略显疲惫，暖色调，电影感，浅景深，16:9`
2. **上传到可灵「图生视频」**：
   - 模型选 Kling 1.5 或 1.6
   - 时长选 5s（免费版限制，够开场用）
   - 引导词（描述运动）：`镜头缓慢推进，屏幕里的直播画面轻微闪烁，人物叹了口气低下头`
3. 生成 2-3 次挑一条最好的，下载 mp4。

### 备选方案（不花钱）
不生成 B-roll，直接用「黑屏 + 大字标题卡」开场，配音念 S1-S2 旁白，3 秒后硬切软件界面。更省事，但冲击力弱一些。

### S2 转折画面（可选）
如果 S2 也想要 B-roll，用同一张图生成第二段，引导词改成：`镜头继续推进，屏幕里的画面开始汇聚成一个发光的文档，代表「回顾」`。

## 三、字幕（剪映智能识别 + 本目录 SRT 校对）

### 推荐：直接导入 SRT（最准）
1. 剪映顶部「文本」→「智能字幕」→「字幕识别」旁有个「**导入字幕**」按钮（或「本地字幕」）。
2. 选 `03-subtitles.srt`。
3. 字幕自动按时间轴铺好。

### 时间轴微调
本目录 SRT 的时间轴是按配音稿估算的。如果你用 AI 配音，实际节奏可能略快/略慢：
- 整体偏快（成片 < 3 分）：在剪映里全选字幕，把每条字幕的「结束时间」往后拉 0.1-0.2s，让字幕停顿感更强。
- 整体偏慢：无需调，字幕自动跟着配音走即可。

### 字幕样式（剪映里统一设）
- 字体：思源黑体 / 阿里巴巴普惠体（免费可商用），加粗
- 字号：移动端看用「中」（剪映默认），桌面端看用「大」
- 颜色：白色 `#FFFFFF`，描边黑色 2px（保证浅色背景也能看清）
- 位置：底部居中，距底边约 8% 屏高
- 动效：不用动效（B 站弹幕已够花，字幕要稳）

### 不要用剪映「自动识别」
剪映「智能字幕」从音频识别的字幕，错字率约 5-8%（专有名词如「Hikami-Go」「灰泽满」必错）。**直接用本目录 SRT**，省去校对时间。

## 四、封面（即梦 / Canva 文字排版）

### 方案 A：即梦生成（最快）
Prompt：
```
电影感科技封面，深蓝渐变背景，中央大字"直播太长没空看？让AI帮你读完"，副标题"2h直播 → 5min文字回顾 · 全自动"，右下角小字"Hikami-Go | 开源"，16:9比例，文字清晰锐利
```
即梦对中文文字渲染一般，生成 4 张挑一张文字最清晰的，PS 微调错别字。

### 方案 B：Canva 模板（推荐，文字最清晰）
1. canva.com 搜「科技视频封面」模板
2. 改文字为：
   - 主：`直播太长没空看？`（一行）/ `让 AI 帮你读完`（一行）
   - 副：`2h 直播 → 5min 文字回顾 · 全自动`
   - 角：`Hikami-Go | 开源`
3. 背景换成深色科技感（搜「cyber」或「dark gradient」）
4. 加一个软件截图缩略图到右下，增加真实感
5. 导出 16:9 jpg，1920×1080

### 封面构图
```
┌──────────────────────────────────┐
│                                  │
│   直播太长没空看？                 │  ← 主标题，大字，左上 1/3
│   让 AI 帮你读完                  │
│                                  │
│   2h 直播 → 5min 文字回顾         │  ← 副标题，中字
│   · 全自动                        │
│                                  │
│                  ┌─────────────┐ │
│                  │ 软件截图    │ │  ← 右下角缩略图
│                  └─────────────┘ │
│   Hikami-Go | 开源                │  ← 角标，最小字
└──────────────────────────────────┘
```

### B 站封面规范
- 尺寸：1146×717（B 站推荐）或 1920×1080（兼容）
- 文字占比 ≥ 30%（B 站首页缩略图小，文字大才看得清）
- 避免红色大面积（B 站默认有些区域是红的，撞色）
- 主体偏左上（B 站有时长标签盖右下角）

## 五、延时镜头（可选，用来延长到 5 分钟）

如果你想让视频接近 5 分钟，在 S5（录播）和 S7（回顾）之间插一段「流水线全过程延时」：

### 录制方法
1. 找一场正在直播或刚结束、状态还是 `recording` / `media_ready` 的场次。
2. OBS 设置「1 帧/秒」延时录制（或正常录后剪映里 30 倍速）。
3. 录制从「录制中」状态 → 自动变「转写中」→ 自动变「回顾中」→ 自动变「已发布」的全过程（可能要 5-15 分钟真实时间）。
4. 剪映里 10-15 倍速回放，压到 60-90 秒。

### 旁白（覆盖在延时镜头上）
```
（背景音乐+轻配音）这是它后台真实跑的样子——
录制完成，自动送进语音识别，
文字稿出来，AI 开始生成回顾，
回顾写好，自动发布到 B 站。
全过程，不用你点一下。
```

这段如果加上，总片长能到 4 分 30 秒左右，刚好填满「3-5 分钟」区间的上半段。

## 六、BGM 选择

### 免费可商用 BGM 来源
- 剪映自带「版权校验」曲库（最安全，B 站不会下架）
- 推荐「科技」「vlog」「lo-fi」类，节奏舒缓不抢旁白

### 推荐 BGM 风格
- 开场 S1-S2（痛点）：略低沉、带情绪
- S3 亮相起：切换到明亮、向上的电子乐
- S4-S9 演示：BGM 降到 -20dB 以下，让旁白清晰
- S10 收尾：BGM 渐强，情绪上扬

### 音量
旁白 -3dB，BGM -20dB 到 -25dB，转场音效 -10dB。

## 七、转场与节奏

### 转场（克制用，别花哨）
- S1→S2：无（B-roll 内部）
- S2→S3：硬切（「揭晓」感）
- S3-S9 段内：不用转场，每段是一个连续录屏
- 段之间：淡入淡出 0.3s
- S10：白闪 0.2s 转场到 GitHub 截图

### 节奏
- 旁白说每一句，画面都要有对应的视觉变化（鼠标移动 / 切 tab / 滚动）
- 避免「画面静止 + 旁白连说三句」——观众会觉得无聊
- 关键信息（如「自动」「免费」「开源」）出现时，可加文字花字强调

## 八、导出参数

| 项 | 值 |
|----|-----|
| 分辨率 | 1920×1080 |
| 帧率 | 30fps（B 站最高 60，但 30 够用且文件小） |
| 码率 | 8-12 Mbps（B 站会二次压缩，源文件高一点更好） |
| 格式 | mp4 / H.264 |
| 音频 | AAC 192kbps |

剪映导出预设选「1080P 高码率」即可。

## 九、检查清单（导出前过一遍）

- [ ] 配音无杂音、无错字（重点听「Hikami-Go」「灰泽满」）
- [ ] 字幕与配音对位（导入 SRT 后抽查 3-5 处）
- [ ] 没有露出 admin token / API key / cookie 路径
- [ ] 软件界面截图清晰，关键文字能看清
- [ ] 封面文字在 B 站缩略图尺寸下可读
- [ ] BGM 不抢旁白
- [ ] 总时长 3-5 分钟
- [ ] 结尾有「项目地址在简介」的引导
