一、准备工作

开始之前,你需要准备几样东西:

  • 一台 Windows 电脑(或 Linux 服务器)。推荐 Windows,双击即用。
  • ffmpeg / ffprobe。如果你下载带 -ffmpeg 后缀的版本,程序自带裁剪版 ffmpeg,无需另装。否则需要自己装 ffmpeg 并加入 PATH。
  • AI 服务密钥(转写和写回顾要用):
    • 转写:阿里云 DashScope(通义听悟) API Key
    • 写回顾:任意一个 —— DeepSeek、通义千问、OpenAI / Claude / 任何 OpenAI 兼容接口
  • 一个 B 站账号(用于登录扫码、发布专栏)。粉丝/切片员建议用自己的小号发布,避免主号风控。
💡 小提示:如果你暂时没有 AI 密钥,也可以先装好、先体验录制和回放下载功能,等需要转写回顾时再配置 AI。

二、下载与安装

到 Releases 页面 下载,有 4 个 Windows 版本可选:

版本适合谁说明
hikami-windows-amd64-desktop-ffmpeg.exe ✨ 自己电脑日常挂着录直播 双击运行,托盘图标 + 无黑窗,自带 ffmpeg,开箱即用
hikami-windows-amd64-desktop.exe 同上,但机器已装 ffmpeg 比上面少 3M,其余完全一样
hikami-windows-amd64-ffmpeg.exe 服务器 / 命令行操作 普通控制台程序,自带 ffmpeg,日志打 stdout
hikami-windows-amd64.exe 同上,但已装 ffmpeg 最精简的控制台版本

命名约定:-ffmpeg = 内嵌 ffmpeg(开箱即用);-desktop = 托盘 + 隐藏黑窗(双击运行)。不确定就选第一个 desktop-ffmpeg。

双击运行(desktop 版)

  1. 下载 exe,放到一个固定目录(别放桌面/下载文件夹,因为程序会在 exe 同目录创建 data/ 和 hikami.db)。
  2. 双击运行。任务栏右下角出现一个"神"图标,防火墙可能询问是否允许联网 —— 选"允许"。
  3. 右键托盘图标 → 「打开管理界面」,浏览器自动打开;或手动访问 http://127.0.0.1:6334。
  4. 关闭程序:右键托盘图标 → 「退出」。日志文件在 %LOCALAPPDATA%\Hikami-Go\hikami.log。
⚠️ 无显示器服务器注意:如果是 Windows Server Core / 以系统服务方式跑,请用非 desktop 版。desktop 版依赖系统托盘(Win32 Shell_NotifyIcon),没有桌面会话时托盘图标无法创建,关闭流程走不通。非 desktop 版走信号监听,能被服务管理器优雅关闭。

命令行运行 / 后台服务(非 desktop 版)

# 命令行直接跑(日志打到终端)
hikami-windows-amd64-ffmpeg.exe

# 想开机自启 + 崩溃重启?用 NSSM 包装成 Windows Service:
# 1. 下载 NSSM(https://nssm.cc/)
# 2. nssm install hikami
# 3. 填 exe 路径,启动类型选"自动"
# 4. 之后用 services.msc / sc start hikami 管理

三、首次启动

第一次打开管理界面,你会看到引导向导(如果 AI 还没配置),带你走完三步。也可以跳过向导,按下面的步骤手动配。

引导向导(推荐)

  1. 系统就绪检查 —— 显示 ffmpeg / yt-dlp 等工具是否探测到。绿色勾表示 OK。
  2. 填写 API 密钥 —— 输入 DashScope 和回顾 AI 的 key,点保存。
  3. 添加第一个主播 —— 粘贴主播的 B 站主页 URL(如 https://space.bilibili.com/12345678),程序会自动识别主播名和 UID。

向导完成后跳转到首页,你应该看到一个已就绪的系统。

手动配置 AI(如果跳过了向导)

点左侧菜单 「设置」,找到下面这些卡片:

设置卡片填什么必填?
DashScope(通义听悟) 阿里云 DashScope 的 API Key;ASR / Tasks URL 通常留默认即可 转写必需
回顾 AI(Recap) 选 provider(DeepSeek / 通义 / OpenAI 兼容 / Anthropic / 本地 CLI),填对应的 API Key 和模型名(如 deepseek-chat) 写回顾必需
VAD 静音裁剪 默认开启,转写前自动裁掉 >2 秒的静音段,省 3-10% 计费时长。不需要可关 可选
AI 搜索(MCP) 填 Brave 或 Tavily 的搜索 API Key,写回顾时 AI 能联网查证。不填则不联网 可选

添加主播

点左侧菜单 「主播」 → 右上角「添加主播」。

  1. 主页 URL:粘贴 https://space.bilibili.com/<UID>(UID 是主页 URL 里那串数字)。
  2. 程序自动识别主播名和 UID,保存。
  3. 新主播出现在列表里,点开主播详情抽屉,可以配置:
    • 自动录制:直播开始自动录音频 + 弹幕
    • 自动转写:录制结束后自动转文字
    • 自动回顾:转写完成后自动生成回顾
    • 发布设置:发布到哪个 B 站账号、哪个文集、是否原创、AIGC 标记等
    • 术语表:这个主播专属的人名 / 游戏术语

典型场景:加一个常看的主播 → 打开「自动录制」+「自动转写」+「自动回顾」,以后他开播你都不用管,第二天打开就是一篇现成的回顾。

🔒 安全提示:程序默认只监听本机 127.0.0.1:6334。如果想从其他电脑访问,必须在 config.yaml 里设 web.admin_token 加密码,否则任何人都能操作你的后台。

四、自动录直播

这是程序最核心的功能 —— 主播开播自动录,你完全不用守着。

开一次自动录制

  1. 在「主播」页打开主播的配置抽屉,确认「自动录制」开关已开。
  2. 主播开播后,程序会在几分钟内检测到(默认每 3 分钟检查一次直播状态)。
  3. 首页顶部状态条会变成「直播中」(橙色),并显示录制时长和音频分段数。
  4. 主播下播后,程序继续录完最后一段,然后自动进入转写流程(如果开了「自动转写」)。

手动触发录制

主播已经在直播但没自动录?在主播列表点「立即检查」按钮,强制探测一次直播状态。探测到开播会立即开始录制。

录制中的稳健性

  • 断线重连:网络抖动、CDN 切换导致断流,程序自动重连,已录的部分不丢。
  • 风控冷却:被 B 站限流时会等待冷却后重试,不会一直硬撞触发更严重的风控。
  • 空文件收尾:有时下播瞬间会产生 0 字节的空分段,程序自动识别并丢弃,不会让空文件污染后续转写。
  • 多分段合并:一场直播因为重连会产生多个音频分段,程序在转写前会自动合并成单个文件。

五、处理回放

不是只能录直播 —— 已经下播的回放也能处理,有三种方式。

方式一:发现回放(推荐)

适合「我想批量看某主播最近都播了什么」。

  1. 进「回顾」页,切到 「回放」 tab。
  2. 点「发现回放」,粘贴合集 URL(主播主页的「合集/列表」页 URL,如 space.bilibili.com/12345678/lists/...)。
  3. 高级选项可填:cookie(留空则默认用已登录的 B 站账号)、标题过滤前缀。
  4. 点「发现」,程序列出该合集所有回放。勾选你想处理的几条。
  5. 点「执行勾选」,程序后台下载,完成后自动转写。

方式二:链接下载

适合「我只想处理这一个具体视频」。

  1. 「回顾」页 → 「回放」tab → 「链接下载」。
  2. 粘贴单个视频 URL(如 https://www.bilibili.com/video/BV1xxx)。
  3. 填标题(必填),可选主播(留空归入「未分类」)。
  4. 点「下载」,程序下载音频后自动转写。

方式三:导入本地文件

适合「我已经有录音文件了,想让程序帮我转写 + 写回顾」。

  1. 「回顾」页 → 「回放」tab → 「导入」。
  2. 选择本地音频文件(mp3 / m4a / wav / flv 等 ffmpeg 支持的格式)。
  3. 填标题(必填),可选主播。
  4. 点「导入」,程序把音频标准化(转 mp3 + 重采样)后进入转写。

六、生成回顾

音频进入转写后,「回顾」页这一行会显示进度,从 录音 → 转写中 → 转写完成。转写完成后就可以生成回顾了。

自动生成(推荐)

如果主播抽屉里开了「自动回顾」开关,转写完成的场次会自动开始写回顾,无需操作。

手动生成

  1. 「回顾」页找到状态为「转写完成」的场次。
  2. 点「写回顾」按钮(行内动作或抽屉里都有)。
  3. 程序调用 AI 生成回顾,通常 1-3 分钟。生成中状态变为 回顾中。
  4. 完成后状态变 已生成,点这一行可以查看回顾的 Markdown 源码,直接编辑修改。

回顾的结构

AI 默认生成的回顾包含五个部分(可在「设置 → 回顾模板」里自定义):

  • 概要 —— 一段话讲清楚这场直播讲了什么
  • 高光时刻 —— 列出几个最精彩的片段,带时间戳
  • 详细内容 —— 按主题分章节展开
  • 精彩语录 —— 主播说的金句
  • 观看建议 —— 适合什么样的观众看
💡 联网查证:如果你在「设置 → AI 搜索(MCP)」配置了 Brave 或 Tavily 的搜索 Key,写回顾时 AI 会主动联网核实术语、人名、事件,减少胡编。生成时间会稍长一些。

失败重试

转写或回顾失败?「回顾」页这一行会显示「失败」,右侧有「重试」和「重置」两个入口:

  • 重试:重跑当前失败步骤(如回顾失败就重写回顾)。
  • 重置:仅 ASR 转写失败时可用,把场次退回到「音频就绪」状态让你重新转写。

七、发布到 B 站专栏

回顾生成完,下一步就是发到 B 站专栏了。

前置:登录 B 站账号

  1. 「设置」页 → 「账号」卡片。
  2. 点「扫码登录」,用手机 B 站 app 扫页面上的二维码。
  3. 登录成功后,程序保存 cookie,后续发布都用这个账号。
  4. 可以保存多个账号(如一个下载用、一个发布用),在主播抽屉里为每个主播指定不同的发布账号。

发布

  1. 「回顾」页找到「已生成」的回顾,点「发布」按钮。
  2. 在发布对话框里确认:标题、专栏分区、文集、是否原创、AIGC 标记、封面。
  3. 选「直接发布」或「存为草稿」(推荐先存草稿,在 B 站 app 里确认无误后再发布)。
  4. 点确认。发布成功后状态变 已发布,并记录发布时间和文章链接。
⚠️ 风控建议:建议用小号发布,不要短时间内连续发多篇,避免被 B 站判定为营销号。程序默认会等回顾生成后再让你手动点发布,不会全自动连发。

八、术语表(减少转错字)

主播的名字、游戏术语经常被 AI 转错 —— 比如「灰泽满 Hazel」可能被转成「挥则慢 黑子」。术语表就是解决这个的。

给主播配术语表

  1. 「主播」页打开主播抽屉 → 「术语表」。
  2. 手动添加:输入错误写法(可选)和正确写法。例如「Hazel」 → 「灰泽满 Hazel」。
  3. 保存后,这个主播后续转写和回顾都会优先用术语表里的写法。

AI 自动发现新词

程序还会在转写过程中自动识别可能的新术语,加到术语表的「候选」列表。「设置 → 术语表」里可以批量复核:AI 配合搜索引擎(如果配了 MCP)帮你确认每个候选要不要采纳。

九、录音自动存网盘

录音文件占地方?可以让程序发布完成后自动上传到 WebDAV 网盘,然后删除本地副本。

  1. 「设置」页 → 「网盘」(WebDAV)卡片。
  2. 填 WebDAV 服务器地址、用户名、密码、远程目录。
  3. 保存。之后每场直播发布完,音频文件自动上传,本地副本删除(数据库里保留索引,界面仍能看到记录)。

不配也能用 —— 程序会把录音留在本地 data/<主播>/<场次>/raw/ 目录。

十、常见问题

启动后打不开管理界面?

  • 确认浏览器访问的是 http://127.0.0.1:6334(注意是 http 不是 https)。
  • 检查端口是否被占用:命令行 netstat -ano | findstr 6334,如果有其他进程占用,在 config.yaml 里改 web.listen 换个端口。
  • desktop 版右键托盘图标 → 「打开管理界面」会自动开浏览器。

启动报错 "ffmpeg not found"?

两种解决:

  • 简单方案:下载带 -ffmpeg 后缀的版本(自带裁剪版 ffmpeg)。
  • 自己装 ffmpeg:从 ffmpeg.org 下载,把 ffmpeg.exe 和 ffprobe.exe 放到 PATH 里或 exe 同目录。

录制 / 转写 / 回顾失败?

  • 看「回顾」页这一行的红色错误提示,会写明是哪一步、什么原因。
  • 点「重试」重跑失败的步骤;ASR 转写失败可以「重置」回退到「音频就绪」。
  • 如果是 AI 接口报错,检查「设置」里的 API Key 和 URL 是否正确、账户余额是否充足。
  • desktop 版日志在 %LOCALAPPDATA%\Hikami-Go\hikami.log;命令行版日志直接打在终端。

主播开播了但没自动录?

  • 确认主播抽屉里「自动录制」开关是开的。
  • 主播列表点「立即检查」强制探测一次直播状态。
  • 确认你的 B 站账号 cookie 还没过期(「设置 → 账号」会显示登录状态)。主播隐藏了开播状态时,程序依赖账号 cookie 才能查到。

从别的电脑访问后台?

默认只监听本机。要远程访问必须加密码:

# config.yaml
web:
  listen: "0.0.0.0:6334"      # 0.0.0.0 = 监听所有网卡
  admin_token: "你的强密码"    # 必填!程序会强制要求

重启程序后,从其他电脑访问 http://<这台电脑的IP>:6334,会要求输入 admin_token。

十一、进阶配置

以上是日常使用。下面这些是可选的进阶项,都在 config.yaml(或管理界面的「设置」页)里改。

配置项作用默认
output_root 录播、数据库存哪个目录 ./data
web.listen 管理界面监听地址。改 0.0.0.0:6334 允许远程访问(必须配 admin_token) 127.0.0.1:6334
web.admin_token 后台访问密码。监听非本机时强制必填 空
vad.enabled 转写前裁掉静音段,省 3-10% 计费时长 true
cron.discovery 定时扫描主播直播状态的间隔。留空则不自动扫(纯手动模式) 空(2026-07-19 起默认禁用)
mcp.enabled 启用 AI 联网搜索。需要配 Brave 或 Tavily Key false

完整配置项见仓库里的 config.full.example.yaml,每个字段都有注释。

配置备份与迁移

换电脑时不用重配。「设置」页 → 「备份」卡片可以导出一个 JSON 包,包含所有设置(密钥单独加密打包)。新机器装好程序后,「导入」这个 JSON 即可恢复全部配置。
